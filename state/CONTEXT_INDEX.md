# Context Index

The reading list for each task. Open **only** these sections. Find a section by searching its heading text (e.g. `## 4.` or `### 4.2`) and read until the next heading of the same level.

File short names:
- **PLAN** = `guides/adspeek-seo-plan.md`
- **TECH** = `guides/adspeek-seo-technical-guide.md`
- **BEST** = `guides/adspeek-seo-best-practices.md`
- **UI** = `guides/ui-ux-design-guide.md`
- **RESP** = `guides/responsive-guide.md`
- **FACTS** = `state/BUSINESS_FACTS.md`

Agent files (`agents/*.md`) are always read in full for the agent that is running; they are short.
